# 🛍️ Shop Order Management System (Python OOP)

A simple **Order Management System** implemented in Python using **Object-Oriented Programming** and `dataclasses`.  
This project demonstrates handling **Products, Customers, Orders, and Order Items** in a shop-like environment.

---

## 📌 Features
- Manage **Products** (add stock, reduce stock, check availability)
- Manage **Customers**
- Create **Orders** and add multiple **Order Items**
- Automatically calculate total order amount
- Demonstrates **OOP principles**:
  - Encapsulation
  - Composition (Order contains OrderItems)
  - Abstraction (business logic hidden inside classes)
